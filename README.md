# kid-python (파이썬 첫걸음)

블록 코딩(엔트리)에서 파이썬으로 넘어가는 초등학생을 위한 학습 앱입니다. 태블릿 브라우저에서 홈 화면에 추가해 쓰고, 진짜 파이썬이 브라우저 안에서 돌아갑니다. 실물 키보드로 쓰는 것을 전제로 합니다.

처음 화면은 세 칸입니다. **배우기**(수업 목록과 이어서 하기), **만들기**(마음대로 쓰고 돌려 보는 곳, 저절로 저장), **찾아보기**(끝낸 수업에서 배운 문법 모음). 스물세 단원, 수업 137편이 들어 있습니다. "출력과 순서"(print, 계산, 몫과 나머지, 한 줄에 여러 값, 오류 읽기, 단원 마무리), "변수"(이름 붙이기, 값 하나만 가리킨다, input, 글자와 숫자, 글자 잇고 세기, 단원 마무리), "정해진 횟수만큼 반복"(for로 반복하기, 반복 안과 밖, i는 0부터 센다, range 더 쓰기, 반복으로 무늬 만들기, 단원 마무리), "조건"(if로 조건 묻기, 같은지 묻기 ==, if와 else, 여러 갈래 elif, 참과 거짓도 값이다, 단원 마무리), "값 바꾸기와 세기"(값을 바꿔 넣기, 합 구하기, 조건에 맞는 것 세기, 곱 쌓기와 가장 큰 값, 약수와 소수, 단원 마무리), "조건이 맞는 동안 반복"(while, 끝나지 않는 반복과 break, 무작위 수, for와 while 고르기, 단원 마무리), "리스트"(만들고 꺼내기, 차례로 돌기, 번호로 돌기, 리스트 바꾸기, 리스트로 계산하기, 짝지은 두 리스트, 단원 마무리), "함수"(def로 명령 만들기, 값을 넘겨받기, 값을 돌려주기, 함수 안의 이름, 함수로 쪼개기, 단원 마무리), "거북이로 그리기"(거북이 움직이기, 반복으로 도형 그리기, 펜 들기·색·굵기, 함수로 도형 만들기, 자리 정해서 가기와 색칠, 단원 마무리: 집 그리기), "움직이는 그림과 게임"(거북이 여러 마리, 움직임 만들기, 키로 조종하기, 닿았는지 알아보기와 점수, 여러 개 한꺼번에, 단원 마무리: 별 받기), "글자 다루기"(글자도 번호로 꺼내기, 글자 차례로 돌기, 글자 잘라 내기, 글자 찾고 바꾸기, 글자를 리스트로 나누기, 단원 마무리: 비밀 편지), "반복 안의 반복"(반복 안의 반복, 한 줄에 이어 쓰기, 줄마다 달라지는 반복, 구구단과 곱셈표, 모든 짝 살펴보기, 단원 마무리: 무늬 그리기), "클래스"(값을 묶어 다니기, 만들 때 값 넣기, 할 줄 아는 일 넣기, 객체 여러 개, 움직이는 객체, 단원 마무리: 별 여러 개 받기), "딕셔너리"(딕셔너리 만들고 꺼내기, 딕셔너리 바꾸기, 딕셔너리 차례로 돌기, 세어서 모으기, 바꿔 쓰는 표, 단원 마무리: 단어장), "표 모양 리스트"(리스트 안의 리스트, 표 차례로 돌기, 줄마다·칸마다 더하기, 표 만들고 바꾸기, 표에서 찾기와 이웃 칸, 단원 마무리: 빙고), "큰 게임 만들기: 미로 탈출"(지도 그리기, 칸으로 걷기, 보석과 출구, 여러 판, 따라오는 유령, 단원 마무리: 내 미로. 처음 해 보는 큰 만들기로, 게임 하나를 여섯 수업에 걸쳐 키웁니다), "문제 푸는 방법"(다 해 보기, 줄 세워서 풀기, 반씩 줄이기, 나머지로 풀기, 규칙대로 흉내 내기. 마무리 수업 없이 뒤에 방법을 덧붙일 수 있게 열어 두었습니다), "파일에 남기기"(파일에 쓰기, 파일 읽기, 이어 쓰기, 쉼표로 나눈 줄, 파일이 없을 때, 단원 마무리: 기록이 남는 숫자 맞히기), "그림으로 재귀"(자기를 부르는 함수, 갔다가 돌아오기, 두 번 부르면 나무, 눈송이, 재귀로 세기, 단원 마무리: 재귀 숲), "더 짧고 편하게 쓰기"(글자 사이에 값 넣기, 값 여러 개를 한 번에, 두 개씩 받는 for, 리스트를 한 줄로, 겹치는 값 없애기, 단원 마무리: 반 성적표), "파일 나눠 쓰기와 import"(파이썬에 들어 있는 모듈, 내 함수를 다른 파일에, 이름을 골라 불러오기, 불러올 때 실행되는 줄, 값과 클래스도 나눠 두기, 단원 마무리: 내 도구 상자), "큰 게임 만들기: 보물 섬"(계획 세우고 첫 걸음, 보물 줍기, 게 피하기, 단계 올리기, 최고 기록 남기기, 단원 마무리: 내 섬 꾸미기. 게임 하나를 여섯 수업에 걸쳐 키우며, 쓰기 문제는 앞 수업에서 통과한 내 코드에서 이어 갑니다), "수학 실험"(오르내리는 우박수, 소수 찾기, 주사위 실험, 1089 숫자 마술, 곱셈 원, 단원 마무리: 곱셈 원 두 송이. 규칙을 컴퓨터로 수백 번 해 보고 늘 그런지 확인합니다). 끝낸 단원은 목록에서 접힙니다.

**그림판**: 프로그램이 `import turtle`로 시작하면 출력 칸 옆에 그림판이 나타나고, 파이썬의 turtle과 같은 이름의 명령(`turtle.forward(100)`, `turtle.left(90)`, `turtle.color("red")`, `turtle.goto(x, y)`, `turtle.begin_fill()` 등)으로 그림을 그릴 수 있습니다. 진짜 turtle은 브라우저에서 돌지 않아서 자주 쓰는 명령만 같은 뜻으로 직접 만들었습니다(`public/py-worker.js`, 화면은 `src/ui/canvas.js`). 그리기 수업의 쓰기 문제는 출력이 아니라 다 그린 그림을 모범 답의 그림과 견줘서 채점하고, 칠판에 본보기 그림을 보여 줍니다(`src/core/drawing.js`). 움직이는 그림과 게임도 만들 수 있습니다: 거북이 여러 마리(`turtle.Turtle()`), 모양과 크기(`shape`, `shapesize`), 한 장면씩 그리기(`turtle.tracer(0)`, `turtle.update()`), 키 입력(`turtle.onkey`, `turtle.onkeypress`, `turtle.listen`), 타이머(`turtle.ontimer`), `time.sleep`. 프로그램이 키를 받기 시작하면 그림판이 키보드를 받고, 그림판 아래에 누를 수 있는 화살표 단추가 나옵니다(Esc로 멈춤).

**파일 칸**: 프로그램이 `open( )`으로 파일을 읽거나 쓰면 출력 칸 옆에 파일 칸이 나타나 파일마다 줄 번호와 내용을 보여 주고, 새로 생긴 파일과 바뀐 파일을 표시합니다. 파일은 한 폴더에만 두고 실행할 때마다 그 폴더를 비운 뒤 정해 둔 파일만 넣어서, 앞 실행에서 쓴 파일이 섞이지 않습니다(폴더를 거쳐 가는 이름은 막습니다). 수업에서는 문제에 딸린 파일을 넣어 돌리고 끝난 뒤의 파일 내용으로도 채점합니다(`files`, `expectFiles`). 만들기에서 쓴 파일은 "내 파일"로 이 기기에 남아 다음에 켜도 있고, 다른 프로그램도 같은 파일을 읽을 수 있습니다(지우기 단추가 있습니다).

배우기 칸의 **연습 문제**에는 새 문법 없이 배운 것으로 푸는 문제가 단원마다 6개씩, 모두 138개 있습니다(`src/content/practice/`). 단원을 고르고 문제를 골라 풀며, 문제마다 기본·응용·도전 표시와 힌트가 있고, 풀고 나면 선생님의 풀이를 보여 줍니다. 푼 문제에는 ✓만 남깁니다(점수는 없습니다).

## 수업은 이렇게 흘러갑니다

1. **강의**: 화면 속 선생님이 목소리와 자막으로 이끕니다. 엔트리 블록과 파이썬 문장을 나란히 보여 주고, 코드를 한 줄씩 실행해 보이고, 아이가 따라 칠 때까지 기다립니다. 건너뛸 수 있습니다.
2. **예측**: 코드를 보고 무엇이 나올지 먼저 고릅니다. 고른 것에 따라 왜 그런지 다르게 알려 주고, 실행해서 확인합니다.
3. **쓰기**: 설명만 보고 직접 씁니다. 틀리면 무엇을 놓쳤는지 짐작해서 말해 주고, 힌트는 단계별로 열립니다(마지막 단계도 정답이 아니라 비슷한 예제입니다). 고장 난 프로그램을 고치는 문제도 있습니다.
4. **심화**: 선택입니다. 풀지 않아도 되고, 풀다가 그만둬도 됩니다.

점수, 별, 순위, 연속 출석은 없습니다.

## 개발

```
npm install
npm run dev      # 개발 서버. 주소 뒤에 ?fast 를 붙이면 소리를 끄고 수업을 빨리 돌려 볼 수 있다
npm test         # 대본 점검 + 모든 문제의 답을 실제 파이썬으로 돌려 검증
npm run build    # dist/ 에 배포물을 만든다
npm run preview  # 배포물을 localhost로 띄운다 (서비스 워커, 오프라인 확인)
```

`master`에 푸시하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 합니다.

## 구조

대본(데이터) → 장면을 만드는 순수 함수 → 재생기, 세 층입니다. 틀은 같은 아이를 위한 주산 앱 JUSAN에서 가져왔고, 선생님 모습도 같습니다.

- `src/content/missions/` 미션 대본(대사, 강의 장면, 예측 문제, 쓰기 문제, 힌트)
- `src/core/` 순수 함수: 장면 만들기(`lesson.js`), 채점과 오답 짐작(`diagnose.js`), 오류 설명(`errors-ko.js`)
- `src/ui/` 화면: 재생기(`player.js`), 칠판(`board.js`), 선생님(`teacher-view.js`), 목소리(`speech.js`), 편집기(`editor.js`), 출력 창(`output.js`), 파이썬 실행 관리(`runner.js`), 기록(`log.js`, `sync.js`)
- `public/py-worker.js` 파이썬을 돌리는 일꾼(웹 워커). 한 줄씩 실행해 보이기도 여기서 한다
- `public/sw.js` 오프라인 저장과 교차 출처 격리 머리말
- `check.html` 부모·개발용 점검 화면(실행 기반 자동 점검, 기록 전송 설정)

파이썬 실행기는 [Pyodide](https://pyodide.org), 편집기는 [CodeMirror](https://codemirror.net)입니다. 엔트리 블록 이름은 [엔트리 공식 문서](https://docs.playentry.org)에서 확인했고, 블록 그림은 직접 그린 단순한 모양입니다.
